# last30days Source Selection Checklist

## Choose `x` when

- [ ] The topic is breaking, viral, campaign-led, or influencer-driven.
- [ ] You need short-form reactions and phrasing.
- [ ] Hashtags, quote posts, and public figures matter.
- [ ] You accept higher volatility and possible viral bias.

## Choose `reddit` when

- [ ] You need longer user reasoning or product experience details.
- [ ] Subreddit communities are central to the market/category.
- [ ] You need pain points, alternatives, and objections.
- [ ] You accept slower but deeper discussion patterns.

## Choose `both` when

- [ ] You need a balanced read: fast signal + deep discussion.
- [ ] The output informs product, marketing, positioning, or risk.
- [ ] You want to compare source-specific sentiment and vocabulary.
- [ ] You are unsure which source is more relevant.

## Before starting

- [ ] Topic is not ambiguous.
- [ ] Date window is defined as recent 30 days.
- [ ] Source selection is `x`, `reddit`, or `both`.
- [ ] Output format is chosen.
- [ ] Search keywords and exclusions are listed.
- [ ] Access method is available or fallback is documented.

## Before finalizing

- [ ] Findings are source-backed.
- [ ] Facts and interpretation are separated.
- [ ] Source limitations are stated.
- [ ] Representative examples include date/source/link or stable ID.
- [ ] No private credentials or auth data are included.
- [ ] Paperclip/Telegram/publishing actions are approval-gated.
