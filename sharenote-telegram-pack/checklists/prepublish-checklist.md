# Prepublish Checklist

## Content
- [ ] Title is clear and matches the note.
- [ ] Summary is Telegram-friendly and not too long.
- [ ] Note contains no credentials, private keys, tokens, or internal-only text.
- [ ] Public sharing is acceptable for the intended audience.

## ShareNote
- [ ] Share Note plugin is installed and enabled.
- [ ] ShareNote account/API state is valid inside Obsidian.
- [ ] `share` frontmatter field contains the final URL or clipboard contains the URL.
- [ ] The generated URL opens in a browser.

## Telegram
- [ ] Target is explicit.
- [ ] For `Pax Team Group`, use it as the default team delivery target only if the user intended team distribution.
- [ ] For `조계종`, send only when the group/context explicitly calls hela/@Paxclawbot.
- [ ] User explicitly approved the exact target and message.

## Final report
- [ ] Note path included.
- [ ] ShareNote URL included.
- [ ] Telegram target included.
- [ ] Any manual steps or failures stated.
